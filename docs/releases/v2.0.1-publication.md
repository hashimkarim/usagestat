# v2.0.1 release qualification

Status: [v2.0.1](https://github.com/hashimkarim/usagestat/releases/tag/v2.0.1)
was published as a stable release on 2026-09-30 at 02:06:42 UTC from
`84bfa891782e1228dd6d2c179f7108e83c5b5aa7` on `main`. GitHub, npm, AUR,
Homebrew and COPR are verified. Ubuntu archive publication remains pending.
Existing v2.0.0 and alpha releases are unchanged.

## Scope

Stable publication retains the qualified Linux x64/ARM64 targets (glibc 2.39+).
Windows/macOS candidates run native release checks but are excluded from stable
downloads and npm. This release adds dashboard Display and Collection settings,
chart details, Antigravity error classification and packaged RPM update support.

Native `/v1` usage readback and optional `agenticdriver.usage.v2` ingestion remain
compatible with v2.0.0 and AgenticDriver RC.2. Existing production credentials,
account bindings and SDK-owned services are outside this release's rollout.
No new model calls are required for the dashboard release.

packaged hook applies the upgrade to an already-running RPM-owned daemon.
