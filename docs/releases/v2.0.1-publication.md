# v2.0.1 release qualification

Status: publication is being prepared from `main`. Public artifacts and package
feeds must be verified before this record is marked published. Existing v2.0.0
and alpha releases are unchanged.

## Scope

Stable publication retains the qualified Linux x64/ARM64 targets (glibc 2.39+).
Windows/macOS candidates run native release checks but are excluded from stable
downloads and npm. This release adds dashboard Display and Collection settings,
chart details, Antigravity error classification and packaged RPM update support.

Native `/v1` usage readback and optional `agenticdriver.usage.v2` ingestion remain
compatible with v2.0.0 and AgenticDriver RC.2. Existing production credentials,
account bindings and SDK-owned services are outside this release's rollout.
No new model calls are required for the dashboard release.

## Evidence

- At version 2.0.1: 162 Rust workspace tests passed, with one systemd-session
  check ignored; the locked CLI/daemon build passed. All 296 provider, 71
  dashboard and two npm launcher tests passed. The service/RPM update suite
  passed 22 tests. Publishing checks ran 58 tests with two Windows-only skips.
  Provider inventory verified all 97 manifests and declared source modes;
  shared icon checks verified 62 linked providers at the unchanged pin.
- Read-only publishing readiness verified existing AUR/Homebrew credentials
  and repository permissions, COPR build permission for the four configured
  Fedora chroots, and PPA signing/upload access. The single-destination doctor
  flags the README's intentionally separate alpha links; manual review confirms
  both stable and alpha destinations match the existing workflow. PPA binary
  availability remains a separate publication check.

The source feature checks and browser validation are recorded in
[dashboard collection validation](../validation/dashboard-collection-customizations-2026-09-30.md)
and [settings/update validation](../validation/dashboard-settings-updates-2026-09-30.md).

after publication.
