# usagestat v2.0.0-alpha.4

This backend alpha ships **97 provider plugins**, a richer dashboard, and faster,
more precise local usage history across Windows, macOS, and Linux.

## Dashboard and accounting

- Adds cost, token, cache, and model breakdowns, source comparisons, daily ledger
  rows, month-to-date/all-time ranges, and portable display preferences.
- Uses smooth quota-history curves and stacked cost charts with tooltips. Missing
  prices, incomplete coverage, and API estimates remain visibly distinguished.
- Saves daily model rows, session-days, cache savings, cost components, and pricing
  provenance. The selected daily source is billing, then local transcripts, then
  ccusage; alternative source rows remain available for comparison.
- Deduplicates repeated Codex cumulative usage, inherited subagent history, and
  repeated Claude message/request records. Reasoning is included in output tokens
  rather than counted twice.
- Caches transcript summaries by profile and refreshes saved model history in the
  background. Compact, bounded HTTP history responses keep large histories usable.
- Adds provider health and quota gauges at `/metrics` and updates the T3 hub's
  cached-usage adapter for current account enumeration and API-call contracts.

See [history accounting](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.4/docs/history-accounting.md)
for source precedence, UTC grouping, estimate pricing, and incomplete data.
API-equivalent estimates are not subscription charges or invoices.

## Providers

The 20 additions are AIXY, Atlas Cloud, Bifrost, CodeRabbit, DevPass, Gemini Apps,
GitKraken, HelmCode, Hugging Face, Hyper, LLMMan, Muse, Nous, Pi, Raycast,
Replicate, TypeSafe, v0, Vercel, and Xkiro. They are **disabled by default**;
enable the providers you use. Seventeen integrations retain pinned upstream
provider code and MIT notices. Shared monochrome/color icons include their
licenses and provenance.

- Claude can read recent matching-account Claude Code quota observations and,
  on supported file-backed Linux/macOS profiles, use a bounded CLI control
  dialogue without a user prompt or inference. OAuth throttling and observation
  age remain respected. See [Claude sources](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.4/docs/claude-usage.md).
- Antigravity uses agy's access token, refreshes expired tokens, isolates login
  caches, and falls back to model quota data for personal accounts. Revoked
  refresh tokens receive a cooldown.
- Updates DeepSeek Platform history, Devin exhausted allowances, Cline browser
  credentials, Command Code grants, LiteLLM monthly fallback, Mistral budgets,
  Venice balances, OpenCode Go unpriced history, and Codex plan presentation.

Provider presence and fixture coverage do not qualify every live account or
optional upstream workflow. Consult the [provider inventory](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.4/docs/provider-compatibility.md).

Download the matching `.sha256` sidecar. Archives contain the CLI, daemon,
dashboard, all 97 plugins/icons, and license notices. Windows also includes a
per-user PowerShell installer. Native archives need no Node, Python, or compiler.

The release workflow builds and tests all five targets, rehearses npm installation
on each, and checks Homebrew and Windows installation before publishing. Separate
alpha package feeds update afterward; feed builds and community review can finish
later than GitHub publication. For npm, use `@hashimkarim/usagestat@alpha` with
Node 24+ and npm 11.5.1+.

## Alpha limitations

This release covers the backend; native Windows/macOS bar frontends are separate.
Windows/macOS binaries remain unsigned and macOS is not notarized. Native CI uses
Ubuntu 24.04, macOS 15, and Windows Server 2025. Older OS minimums, ordinary desktop
login/reboot, distinct-version service upgrades, and real provider accounts still
need qualification. Linux requires glibc 2.39+; Windows ARM64 and musl/Alpine
payloads are not included. Stable package channels remain on their existing release.
