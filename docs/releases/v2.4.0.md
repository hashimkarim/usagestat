# UsageStat 2.4.0

Quota checks are now cheap. The Codex and Claude plugins used to run ccusage on every poll, re-reading every local transcript; they now read the summary the daemon already builds in the background. On a machine with 20 GB of Codex logs, the daemon went from about 0.8 CPU cores and 140 GB of disk reads per 10 minutes to 0.02 cores and under 1 GB. The local log cache also stops rewriting its full file every minute.

Codex totals are corrected. Recent Codex logs record each request twice, and the daemon counted most of them twice, so History and cost estimates were about 60% high. Totals now match the raw logs, including archived sessions that ccusage leaves out. The local log cache rebuilds once on first start.

Prices and provider logos update without an app release. The daemon downloads the published price catalog and the latest stable AgenticDriver provider-icons release daily, verifies them, and keeps the bundled copies as a fallback. Usage is priced at the rate that applied on its day, so a later price change does not alter past costs. GPT-6.2 Astra and Sol are now priced. Either download can be turned off (`pricingUpdates = false`, `iconUpdates = false`).

Dashboard settings are split into tabs and show only providers that are collecting.

Costs remain API-equivalent estimates from local logs, not invoices. A daemon running 2.3.1 or later restarts itself into 2.4.0 after a Linux package upgrade; Homebrew still needs `usagestat daemon relocate` after `brew upgrade`, and Windows a stop and start.
