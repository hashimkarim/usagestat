# UsageStat 2.3.1

A running managed daemon now restarts itself into an upgraded executable. Once a minute it checks its installed `usagestatd`; when a package manager has replaced it and the new file has settled for 30 seconds and reports a `usagestatd` version, the daemon shuts down normally and restarts in place, keeping its process, settings, T3 mode and autostart. This works for RPM, deb, AUR, npm and manual installs, with no package scriptlet. A stopped daemon stays stopped.

The RPM no longer ships its post-transaction restart hook or depends on `python3`. On SELinux-enforcing Fedora that hook's call into the user session failed silently, so upgrades left the old daemon running.

**Upgrading to 2.3.1 needs one manual restart** (`usagestat daemon stop`, then `usagestat daemon start`), because a 2.3.0 daemon does not have the watcher. Homebrew still needs `usagestat daemon relocate` after `brew upgrade`, and Windows still needs a stop before upgrading and a start after.
