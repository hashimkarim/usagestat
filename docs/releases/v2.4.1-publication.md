# v2.4.1 publication

[v2.4.1](https://github.com/hashimkarim/usagestat/releases/tag/v2.4.1) was
published on 2026-11-24 at 17:59:40 UTC from `a86755f` by the first attempt of
the [tagged workflow](https://github.com/hashimkarim/usagestat/actions/runs/45450780577),
after all five native builds, the Windows installer rehearsal, both Homebrew
rehearsals and all five npm installation rehearsals passed. It published:

- the GitHub release: 28 assets;
- npm: 2.4.1 with all five platform packages;
- Homebrew, AUR and COPR.

The PPA job uploaded the source and then timed out waiting for Launchpad, as
for 2.3.1 through 2.4.0. Launchpad accepted `2.4.1-1ppa1`.

The `main` CI run for the same commit failed two `run_ingestion` daemon tests on
the Linux x86_64 runner (a 200 status for a first submission and a dropped
connection); they passed locally and on re-run. The maintainer's machine went
from 2.4.0 directly to 2.4.2.
