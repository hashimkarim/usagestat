# usagestat v2.0.0

The v2 stable backend targets Linux x64 and ARM64 with glibc 2.39 or newer.
It includes the CLI, daemon, dashboard, 97 provider plugins, shared icons, and
optional durable SDK run ingestion. Windows/macOS stable qualification remains
open; their existing alpha.4 packages are not promoted or overwritten.

## Changes

- Native SDK run ingestion accepts `agenticdriver.usage.v2`, with a protocol
  handshake, exact host/provider/account/subject authorization, separate bearer
  credentials, transactional deduplication, retention, and optional durable
  forwarding. `--no-poll` supports a separate ingestion-only service.
- Provider quotas retain separate Antigravity session/weekly windows, including
  Starter's weekly-only allowance. Missing measurements remain unknown.
- Mistral prices match event, billing unit, region and service tier, including
  fine-tuning. Missing prices produce an explicit partial spend total.
- Z.ai identifies unavailable quota shapes. Muse/Raycast cookie handling and
  pinned bundled providers are updated. Cloudflare challenges are distinguished
  from expired sessions; TypeSafe access can still be blocked.
- Local estimates include Sonnet 5.5. Cache version 6 rescans unchanged local
  logs; saved billing/ccusage rows and source precedence remain intact.
- Includes the v2 alpha dashboard/history improvements: model and cost
  components, cache savings, selected versus alternative daily sources, compact
  history responses, and deduplication of repeated local usage records.

## Consumer migration

Existing `GET /v1/providers`, `/v1/usage` and `/v1/usage/:providerId` readback
remains supported. No new HTTP major version or application login migration is
required. The optional `/v0/management/*` T3 compatibility API stays separate.
Administrative readback is not a user-scoped authentication API.

AgenticDriver's published `0.2.0-rc.1` optional quota adapter requests nonexistent
`/v1/limits` routes. Use a subsequent SDK release containing source correction
`88daf7e52a956621389846e997a275ad97f9ae4a`, or a deliberately pinned build of that
source. The corrected SDK derives `agenticdriver.usagestat-limits.v1` from usage
snapshots; update consumers validating the former `crossusage.limits.v1`
literal. Existing desktop native readback already uses the correct endpoints.
This backend release does not silently upgrade SDK packages or running hosts.

Map each authenticated application identity to its explicit backend instance.
Preserve original measurement timestamps and failure states; retained metrics
in a failed snapshot must not become available quota. New provider labels may
produce new derived resource keys. Quotas are separate from per-run metering.

Run ingestion is opt-in. Follow [its contract](../run-ingestion.md), provision
independent backend credentials and exact bindings, and check
`GET /v1/run-usage/protocol` before capture. Old event schemas are rejected.
An acknowledgement follows local SQLite commit; retries resend the same event
and never rerun execution. Run records are not added to quota/daily totals.
Capture failure remains separate from execution success.

API-equivalent estimates are not subscription charges or invoices. Current
dated rates are applied to local transcript estimates, including historical
events; past price schedules are not reconstructed. See
[history accounting](../history-accounting.md).

## Installation and upgrade

Native Linux archives need no Node or Rust runtime. Verify the matching SHA-256
sidecar. npm requires Node 24+ and npm 11.5.1+ and installs the same native
artifacts through exact-version optional dependencies:

```sh
npm install --global @hashimkarim/usagestat@2.0.0 --include=optional --ignore-scripts
```

Use the [installation guide](../installation.md) and
[publication record](v2.0.0-publication.md) for actual channel availability.
Before replacing an owned running installation, record its version and daemon
state, stop it using that installation's supported lifecycle commands, and
preserve its configuration/history and previous binaries for rollback. Restore
the previous running/autostart intent and verify health after updating. Do not
replace a daemon managed by another installation or delete user credentials.

The shared `@agenticdriver/provider-icons` pin remains `0.1.0-alpha.1`.
Provider presence does not qualify every real account, browser, or IDE version.
TypeSafe Cloudflare access and Windows/macOS stable qualification remain known
limitations; see the [provider inventory](../provider-compatibility.md).
