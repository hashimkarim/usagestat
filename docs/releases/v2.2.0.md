# UsageStat 2.2.0

Adds GPT-6.1 Sol API-equivalent cost estimates, including cached input, cache writes and long-context rates. Saved local transcripts are reparsed to include the new pricing; retained billing charges remain authoritative.

Adds optional SiliconFlow, Tripo, OpenDesign and Google Developer providers, bringing the catalog to 124 providers. Updates Helmcode, TypeSafe, MuseAI, Trae and WorkBuddy readbacks from reviewed upstream sources.

Improves Cursor encrypted-token handling and read-only stable CLI fallback, Perplexity manual-session readback, Codex monthly windows, Kimi monthly breakdowns, OpenCode credentials and Synthetic weekly plans. JetBrains gains modern quota parsing and optional bounded local observations while preserving explicit profile selection.

Validated with synthetic provider fixtures and native tests. Provider availability does not imply every real account is credential-tested. Existing unsigned artifact and platform qualification policies remain in effect.
