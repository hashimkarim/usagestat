[GitHub prerelease](https://github.com/hashimkarim/usagestat/releases/tag/v2.0.0-alpha.4)
resolves to source commit `bd5b7a162d7a3ddcf17995d3d20cb4b8cbd6d64b`.
The dashboard thread's release handoff was reviewed before committing the backend
and dashboard together.

## Verification

- The [final native suite](https://github.com/hashimkarim/usagestat/actions/runs/36429372810)
  passed on Linux x64/ARM64, macOS Intel/Apple Silicon, and Windows x64, including
  its aggregate evidence check.
- The tagged release passed workspace/provider tests, archive verification,
  npm installation on all five platforms, Homebrew installation/upgrade/removal
  on both Mac architectures, and Windows per-user installation.
- All 28 downloaded public GitHub assets matched their recorded SHA-256 digests.
  The live tag, five-target aggregate, and artifact source commit agreed.
  The downloaded Linux x64 archive passed the installed-runtime checks.
- All six public npm packages had the exact integrity and metadata of the tested
  CI tarballs. A fresh public `@alpha` install with scripts disabled produced
  alpha.4 CLI/daemon binaries and all 97 provider manifests.
- GitHub's stable release remained `v1.0.3`. The existing npm `latest` tag remained
  `2.0.0-alpha.1`; the `alpha` tag advanced to `2.0.0-alpha.4`.

## Publication recovery

The [release run](https://github.com/hashimkarim/usagestat/actions/runs/36430509255)
contains publication failures as well as successful tests. Those failures do not
indicate replacement or rebuilding of the released binaries:

- Homebrew's initial asset download received a GitHub HTTP 500 before changing
  the tap. The [targeted retry](https://github.com/hashimkarim/usagestat/actions/runs/36433353091)
  published successfully and passed both public Mac installation checks.
- WinGet's CI credential could not create a submission branch (HTTP 404).
  The same publisher completed the submission with existing local GitHub
  authentication, after comparing all three manifests against the CI-tested
  recipes and verified public release bytes. No repository secret was changed.
- npm accepted the ARM64 Linux package, but public visibility exceeded the
  publisher's ten-minute wait. Once visible, the npm job was rerun with the same
  saved CI tarballs, skipped matching published packages, and successfully
  published and verified the remaining packages.
- Launchpad accepted the Ubuntu upload, but the original status check timed out.
  The [targeted retry](https://github.com/hashimkarim/usagestat/actions/runs/36435037231)
  monitors the existing upload without resubmitting it.

The unsigned Windows/macOS and desktop/minimum-OS qualification limits in the
[release notes](v2.0.0-alpha.4.md) still apply.
