# v2.3.2 publication

[v2.3.2](https://github.com/hashimkarim/usagestat/releases/tag/v2.3.2) was
published on 2026-11-19 at 14:27:01 UTC from
`99b4b6f1fdf515f10844496ea03a5ce80153055a`, after all native builds and tests
passed on `main`. It is the first stable release for macOS and Windows.

The [tagged workflow](https://github.com/hashimkarim/usagestat/actions/runs/44540654090)
passed all five native builds, the Windows installer rehearsal, both Homebrew
rehearsals and all five npm installation rehearsals (Ubuntu x64/ARM64, macOS 15
Intel/Apple Silicon, Windows Server 2025). It published:

- the GitHub release: 28 assets, including the macOS and Windows archives and
  `Install-Usagestat.ps1`;
- npm: `latest` is 2.3.2, with all five platform packages (Linux x64/ARM64 gnu,
  macOS x64/ARM64, Windows x64);
- Homebrew, with `on_linux` and `on_macos` blocks;
- AUR and COPR.

The PPA job failed before uploading because Launchpad's API timed out. A
[PPA-only retry](https://github.com/hashimkarim/usagestat/actions/runs/44549099350)
uploaded the source; its status poll timed out again, and 2.3.2 was pending on
Launchpad at the time of writing. It publishes when Launchpad finishes.

On the maintainer's Fedora machine, `dnf upgrade` from 2.3.1 was followed, about
a minute later, by the running daemon restarting itself into 2.3.2 with the same
process id. This was the first self-restart through an RPM upgrade. Scoop,
WinGet and Chocolatey still carry only the alpha.
