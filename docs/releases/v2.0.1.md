# Usagestat v2.0.1

This stable update adds independent dashboard settings, local provider setup,
chart details and RPM service update support. Stable archives and npm packages
target Linux x64/ARM64 with glibc 2.39+. Windows/macOS remain on the existing
separate alpha channel; native candidate checks do not expand stable support.

## Dashboard settings

Open **Settings** in the dashboard. **Display** configures this browser's visible
providers and trackers, names, pinning/order, quota choice, colours, themes,
layout, reset times, thresholds, notifications and keyboard controls. Provider
logo menus offer the provider itself and its related variants, with separate
monochrome/colour choices. Custom PNG/JPEG/WebP uploads, styled file controls and
checkboxes work on desktop and mobile. Display settings remain independent of
UsageStat Bar and can be imported/exported without provider credentials.

**Collection** edits the shared backend's provider sources, credentials, polling,
plugin paths and explicit account instances. Hiding a provider does not stop
measurement; pausing collection preserves saved usage and history. Configuration
changes reload without a daemon restart, after any current probe completes.

Collection is available only directly on a local polling daemon's loopback
address. Select its private `dashboard-setup.key` with **Choose local setup key**
at the path shown on the page. The private file is never returned over HTTP or
saved in display preferences; a tab-local capability expires when the daemon
restarts. Write-only credential fields preserve saved values when left untouched.
This setup does not create SDK grants or account bindings. Ingestion-only and
remote listeners do not expose setup routes.

See [dashboard settings](https://github.com/hashimkarim/usagestat/blob/v2.0.1/docs/dashboard-settings.md)
and the [local collection API](https://github.com/hashimkarim/usagestat/blob/v2.0.1/docs/dashboard-collection-api.md).

## Charts and provider status

Quota, trend, daily, calendar, model, token and cost charts provide hover,
keyboard-focus and tap details for available measurements, windows, sources,
freshness and pricing coverage. Missing values remain unknown; failed cached
snapshots do not become successful current usage. API-equivalent estimates
remain distinct from subscription charges and invoices.

Antigravity quota/license denials are distinguished from expired authentication.
Unavailable or retained fallback observations keep their actual status. TypeSafe
Cloudflare access remains a known provider limitation; this release does not
claim a challenge bypass or universal account qualification.

## Upgrade and compatibility

Upgrade the daemon as well as the CLI to load the new dashboard. Stable RPMs now
include the stable COPR feed, an optional daily update timer and a transaction
hook that restarts an already-running RPM-owned native service after its binary
changes. The hook preserves stopped services, autostart intent, configuration,
history and SDK-owned installations. Enable daily downloads using the packaged
timer if desired; other installation channels still use their supported restart
commands. Existing v2.0.0 RPMs gain these hooks when upgraded to v2.0.1.

```sh
sudo dnf upgrade usagestat
sudo systemctl enable --now usagestat-rpm-update.timer
```

The npm package uses exact-version native dependencies and needs Node 24+ and
npm 11.5.1+:

```sh
npm install --global @hashimkarim/usagestat@2.0.1 --include=optional --ignore-scripts
```

There is no new HTTP major version, deprecated readback route, SDK event schema
or application authentication migration. `/v1/providers`, `/v1/usage` and optional
`agenticdriver.usage.v2` run ingestion retain their stable contracts, identity
bindings, separate credentials, deduplication and accounting semantics. AgenticDriver
RC.2 remains compatible. The shared provider-icons pin remains `0.1.0-alpha.1`.
Existing releases and their assets are immutable.

Use the [installation guide](https://github.com/hashimkarim/usagestat/blob/main/docs/installation.md)
and [publication record](https://github.com/hashimkarim/usagestat/blob/main/docs/releases/v2.0.1-publication.md)
for per-channel availability and verification. A queued package build is not an
installed upgrade; preserve each installation's existing profile and service owner.
