# UsageStat 2.3.0

Adds per-repository and per-branch cost. `usagestat project` shows what Claude Code, Codex, Gemini CLI and Amp cost in the repository you are in, with `--branches` for cost per git branch; the dashboard's Projects tab expands each project by branch. Agent worktrees (T3, Claude Code, Codex) and subfolders count toward their main repository. Gemini CLI and Amp join Claude Code and Codex as local log sources.

Adds run-out forecasts: quota bars and the new `usagestat statusline` show when a window will run out before it resets at the current pace. New commands: `usagestat sessions` ranks the costliest sessions, `usagestat whatif <model>` recosts recent usage at another model's API rates, and `usagestat top` is a live terminal view.

Adds opt-in integrations that do nothing until configured: event hooks and webhooks (`quota_threshold`, `quota_reset`, `quota_forecast`, `provider_failing`, `provider_recovered`, `budget_threshold`), monthly `[[budgets]]` per project, `usagestat mcp` for agents, and `[sync]` for totals across machines through a shared folder.

The dashboard gains spend alerts and a month projection, plan value against a subscription price, CSV export, chart span and grouping controls, an hour-of-day view, combined account cards, a shareable PNG summary and live provider incident badges. A Grafana dashboard for `/metrics` ships in `docs/grafana`.

The local log cache is rebuilt once from logs on first start. Costs remain API-equivalent estimates from local logs, not invoices. Validated with synthetic fixtures and native tests; existing unsigned artifact and platform qualification policies remain in effect.
