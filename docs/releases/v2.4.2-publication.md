# v2.4.2 publication

[v2.4.2](https://github.com/hashimkarim/usagestat/releases/tag/v2.4.2) was
published on 2026-11-24 at 19:21:54 UTC from `35c9731`.

The first attempt of the
[tagged workflow](https://github.com/hashimkarim/usagestat/actions/runs/45464188479)
failed before publishing anything: on Windows, the
`lost_destination_acknowledgement_retries_the_same_event_once` fixture read
from an accepted socket that had inherited its listener's non-blocking mode
and got `WouldBlock` (the same fixture failed v2.4.0's first attempt). The
fixture is fixed on `main` in `effa762`; the daemon already resets accepted
sockets to blocking. Re-running the failed job passed all native builds and
rehearsals and published:

- the GitHub release: 28 assets;
- npm: `latest` is 2.4.2, with all five platform packages;
- Homebrew, AUR and COPR.

The PPA job uploaded the source and then timed out waiting for Launchpad, as
before; Launchpad accepted `2.4.2-1ppa1`.

On the maintainer's Fedora machine, `dnf upgrade` from 2.4.0 was followed by the
running daemon restarting itself into 2.4.2 with the same process id. It serves
the 2026-11-24 price catalog (bundled and downloaded). Its first start rebuilds
the local log cache once (cache v15) to record Codex service tiers.
