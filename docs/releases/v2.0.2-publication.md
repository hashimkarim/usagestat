# v2.0.2 release qualification

Status: release preparation. Publication of the new stable `v2.0.2` version is
authorized; the tag, public assets and package feeds have not yet been verified.
This record will be completed with immutable coordinates and live evidence after
the tagged pipeline finishes. Existing releases remain unchanged.

## Scope

Stable publication retains Linux x64/ARM64 with glibc 2.39+. Windows/macOS
candidates run native release checks but remain excluded from stable downloads
and npm. The release updates provider compatibility, native Codex accounting,
OpenCode 2 storage and dashboard setup hints, and adds three disabled-by-default
providers. See [release notes](v2.0.2.md).

Native `/v1` readback, optional `agenticdriver.usage.v2` ingestion and the shared
provider-icons `0.1.0-alpha.1` pin remain compatible. No model calls, production
credential changes, new identity grants or installed-service rollout are part of
this release. TypeSafe Cloudflare access and new provider live sessions retain
their explicit qualification limits.

## Pre-publication evidence

- At version 2.0.2, 178 Rust workspace tests passed, with one existing
  systemd-session test ignored. The locked CLI/daemon build passed, as did
  the workspace check using the qualified Rust 1.89.0 toolchain.
- Publishing tests passed 58 cases with two Windows-only skips on Linux;
  service/RPM update tests passed 22 cases, and both npm launcher tests passed.
  All 390 provider/dashboard JavaScript checks passed. The actual pinned Bar
  contract passed seven checks and native synthetic local-history acceptance
  passed six checks using the 2.0.2 debug binaries.
  All 100 provider manifests and modes, 20 vendored source hashes/licenses and
  62 shared icon mappings passed their checks.
- Read-only readiness verified AUR/Homebrew authentication and repository
  permissions, COPR build access for all four configured Fedora chroots, and
  PPA signing/upload permission. The single-destination doctor flags this
  README's intentional separate alpha links; manual review confirms they
  match the existing stable/alpha workflow and are not destination drift.
- The direct Noble amd64 APT index now contains the earlier 2.0.1-1ppa1
  package. New 2.0.2 publication remains a separate check below.

The source desktop/mobile browser checks used a private isolated dashboard with
every collector paused. Setup guidance and blank-field/save behavior passed,
with no horizontal overflow or console errors. Synthetic/native fixtures do
not establish authenticated access to a new provider account.
