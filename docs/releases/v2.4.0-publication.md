# v2.4.0 publication

[v2.4.0](https://github.com/hashimkarim/usagestat/releases/tag/v2.4.0) was
published on 2026-11-20 at 16:57:39 UTC from
`a6d134e`, after all native builds and tests passed on `main`.

The first attempt of the
[tagged workflow](https://github.com/hashimkarim/usagestat/actions/runs/44774057971)
failed before publishing anything: on the Intel macOS runner, the
`lost_destination_acknowledgement_retries_the_same_event_once` fixture's mock
server hit its 2-second read timeout. The same commit had passed that test on
every platform in `main` CI. Re-running the failed job passed all five native
builds, the Windows installer rehearsal, both Homebrew rehearsals and all five
npm installation rehearsals, and published:

- the GitHub release: 28 assets;
- npm: `latest` is 2.4.0, with all five platform packages;
- Homebrew, AUR and COPR.

The PPA job uploaded the source and then timed out waiting for Launchpad, as
for 2.3.1 and 2.3.2. Launchpad accepted `2.4.0-1ppa1`; it was Pending at the
time of writing and publishes when Launchpad finishes.

On the maintainer's Fedora machine, `dnf upgrade` from 2.3.2 was followed about
a minute later by the running daemon restarting itself into 2.4.0 with the same
process id. It then served the bundled 2026-11-20 price catalog. The published
`pricing/models.json` and the AgenticDriver provider-icons `v1.1.0` release are
picked up by running 2.4.0 daemons within a day of start.
