# usagestat v2.0.0-alpha.1

First alpha of the cross-platform **backend**: the Rust CLI, background daemon,
local dashboard/API and bundled provider plugins. This release is intended for
early testing on Windows, macOS and Linux. The native Windows/macOS usagestat-bar
frontends are separate work and are not included.

Download the matching `.sha256` sidecar with each archive. Windows also includes
`Install-Usagestat.ps1` and its checksum for per-user installation, plus a target

no Node, Python, Rust compiler or WSL.

## Included

- Per-user macOS LaunchAgent and Windows scheduled-task management alongside
  Linux systemd, with independent running/autostart controls and retained T3 state.
- Native config/data locations, private state, portable helper execution and
  installed resource discovery, including Unicode/spaces and dev profiles.
- Windows credential-store access, provider path and IDE discovery improvements,
  explicit capability/diagnostic states, and scoped browser import where supported.
- Windows installation, replacement, rollback, interruption recovery and removal;
  retained-version daemon relocation/recovery for package managers.
- npm launcher/native packages and five-platform installation rehearsals. Public
  npm publication remains pending; this alpha is distributed through GitHub.

## Alpha limitations

- Windows and macOS downloads are **unsigned**; macOS is **not notarized**.
  Publisher trust/Gatekeeper/SmartScreen behavior on ordinary desktops is pending.
  Checksums establish integrity against the chosen inputs, not a signing identity.
- macOS 11 and Windows 10/Server 2016 are build targets, not verified minimums.
  Windows ARM64, 32-bit Windows and musl/Alpine are not included.
- Native CI exercises service/install/recovery and synthetic provider credentials.
  Normal login/reboot/sleep, actual provider/browser/IDE accounts, distinct-version
  upgrades and native bar integration still require desktop acceptance.
- Provider/source support varies. Windows Chromium App-Bound `v20` cookie import
  is explicitly unsupported; use a provider-supported manual/OAuth/API route where
  available. No universal browser-session import is promised.
- Existing stable package repositories and the stable GitHub release remain on
  their current versions. This alpha does not promote those channels.

Use the [provider matrix](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.1/docs/provider-compatibility.md)
and [desktop test handoff](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.1/docs/desktop-qualification.md)
to report the exact OS/app version, source and result. Do not attach credentials,
management keys, browser databases or auth-import JSON to an issue.
