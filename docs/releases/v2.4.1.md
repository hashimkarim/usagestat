# UsageStat 2.4.1

Provider fixes from the latest upstream review. Notion works again for workspaces on the new allowance format, which previously stopped with "not tracked"; it now shows the Standard and Select pools and the Notion Credits balance. Amp no longer shows a made-up $0.00 for workspaces paid by an enterprise. Grok shows the prepaid balance. MiMo can use a Token Plan API key instead of browser cookies. OpenAI API balances can be scoped to an organization. MuseAI and Claude Platform pick up small upstream fixes, and TrustedRouter is a new provider.

GPT-6 Rosalind prices are corrected to OpenAI's published rates; running daemons already received this through the price catalog. Fresh installs bundle provider-icons 1.1.0.

A daemon running 2.3.1 or later restarts itself into 2.4.1 after a Linux package upgrade; Homebrew still needs `usagestat daemon relocate` after `brew upgrade`, and Windows a stop and start.
