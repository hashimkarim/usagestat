# usagestat v2.0.0-alpha.2

This alpha bundles **all 77 provider plugins**, up from 61 in alpha.1, and brings
the September provider updates to the Windows, macOS and Linux backend releases.

## Providers and fixes

- Adds AIAND, ClawRouter, Cline Pass, CodeBuddy, DeepInfra, IBM Bob, LongCat,
  Notion, Qoder, Qwen Cloud, Sakana, Sub2API, Wayfinder, xAI, ZenMux and Zoommate.
  These 16 plugins are disabled by default; enable the providers you use in settings.
- Adds upstream quota, authentication and account-selection improvements, including
  Codex token refresh, Kiro profile routing, MiniMax endpoints, ElevenLabs errors,
  OpenRouter totals, Poe quota periods, Moonshot currency and Command Code labels.
- Makes exhausted Kimi monthly membership the primary quota in the dashboard.
- Excludes inherited Codex subagent history from local usage totals and avoids
  counting repeated cumulative usage records twice.
- Adds explicit Devin web bearer-token and organization configuration on all three
  operating systems, with account isolation and documented environment overrides.
- Fixes dashboard token rounding at the K/M/B boundaries.

The release now checks the provider inventory and JavaScript regression tests
before building. Packaging refuses untracked provider manifests and bundles
upstream license notices, preventing another development/release inventory gap.

Download the matching `.sha256` sidecar. Archives contain the CLI, daemon,
dashboard, all 77 plugins/icons and license notices. Windows also has the
per-user PowerShell installer. Native archives need no Node, Python or compiler.

The release workflow updates the separate alpha AUR, Homebrew, COPR, PPA, Scoop
and npm channels and submits the Windows community packages after installation
checks. Feed builds and community review can take longer than GitHub publication.
For npm, select `@hashimkarim/usagestat@alpha` with Node 24+ and npm 11.5.1+.

## Alpha limitations

This is the backend alpha: native Windows/macOS bar frontends are still separate
work. Windows/macOS binaries remain unsigned, and macOS is not notarized. Native
CI uses Ubuntu 24.04, macOS 15 and Windows Server 2025; older OS minimums, ordinary
desktop login/reboot and real provider accounts still need qualification. Linux
requires glibc 2.39+; Windows ARM64 and musl/Alpine payloads are not included.

Provider availability describes bundled plugins, not verified credentials for
every account/source. See the [provider matrix](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.2/docs/provider-compatibility.md)
and [manual Devin configuration](https://github.com/hashimkarim/usagestat/blob/v2.0.0-alpha.2/docs/provider-paths.md).
