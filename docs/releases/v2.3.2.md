# UsageStat 2.3.2

Stable releases now cover macOS and Windows as well as Linux. The daemon and CLI are the same as 2.3.1.

- **macOS 11+**, Apple Silicon and Intel: `brew install hashimkarim/tap/usagestat`, npm, or the `usagestat-macos-*.tar.gz` archives.
- **Windows 10 / Server 2016+**, x64: npm, or the `usagestat-windows-x86_64.zip` archive with the per-user `Install-Usagestat.ps1` installer.
- **Linux** x64/ARM64 with glibc 2.39+: unchanged, through npm, Homebrew, AUR, COPR, the Ubuntu PPA and the archives.

macOS and Windows binaries are unsigned. Release CI installs and runs them on macOS 15 (both CPUs) and Windows Server 2025; older versions within the stated floors are untested. Desktop bar frontends for macOS and Windows are not included, and the Scoop, WinGet and Chocolatey feeds still carry only the alpha.

A daemon running 2.3.1 on Linux restarts itself into 2.3.2 after a package upgrade. Windows still needs a stop before upgrading and a start after; Homebrew needs `usagestat daemon relocate` after `brew upgrade`.
