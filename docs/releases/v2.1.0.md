# UsageStat v2.1.0

This stable release expands the provider catalog and updates quota and billing
compatibility. New providers are disabled by default. Stable downloads and npm
packages target Linux x64/ARM64 with glibc 2.39+; Windows/macOS retain their
separate alpha channel and qualification limits.

## Provider additions and source choices

Twenty opt-in providers bring the bundle to 120: Abliteration, Aerostack,
Chatbox, Claude Platform, Cosmic, Exa, Fal, Flora, FutureAGI, Langdock, Linkup,
Munito, Parallel, Sail Research, Sofya, Soniox, Tavily, TinyAPI, Trae CN and X API.
Enable only the providers you use under **Settings → Collection**. Setup fields
include the secondary secrets and organization/project/workspace identifiers
required by each source.

Vercel personal budgets are an explicit alternative to AI Gateway balance and
require a separate Vercel access token. QwenCloud Team Token Plan uses the
configured Qwen session at its selected billing scope. An empty alternative
source does not silently switch accounts. Gemini Apps retains its provider ID
and `GEMINI_COOKIE` alias while using the current GraphQL usage endpoint.

Bundled fetchers retain reviewed upstream source hashes and licenses. Native
cookie sessions constrain credentials and CSRF echoes to reviewed HTTPS routes.
Manual sessions do not imply automatic browser import or verified access to a
live account. TypeSafe includes the upstream browser User-Agent, while
Cloudflare challenge acceptance remains unqualified.

## Quota and accounting corrections

- **OpenCode Go:** the completed credential-import migration determines when
  database credentials become authoritative. Pre-import empty tables retain
  the live auth-file path; post-import logout never resurrects that file.
  Zero-usage full-session reset placeholders are omitted using the server clock.
- **Claude:** reset-grant inventory is requested hourly across restarts while
  ordinary quota reads continue. Valid optional cloud credits retain their
  balance, expiry and locked status separately from subscription quotas.
- **Cursor:** unified weekly pools become primary without duplicated model
  lanes, while enterprise request allowances retain precedence. Stable and
  Nightly share the parser while keeping their selected profiles separate.
  Native event history accepts complete pages of reported charges, rejects
  overlaps and inconsistent counts, and falls back to CSV when billing evidence
  is missing. Private derived caches are scoped to account, profile and timezone.
- **Antigravity:** quota summaries merge daily and production hosts. Known shared
  pools and the separate Argon weekly pool preserve their identity; unknown,
  disabled and recognized-empty responses do not become fabricated quotas.
- **Ollama:** balance readback separates included allowance and purchased credits,
  with the legacy path retained when the balance endpoint returns 404.
- **Kimi:** current ratio pools and expiring bonus credits are supported.
  Exhausted monthly pools remain primary, including membership-only responses.
- **xAI:** optional invoice previews are labeled as live estimates and do not
  become retained billed charges. X API remains a separate provider.

Existing bundled definitions also receive upstream transport and parsing fixes,
including Helmcode routing, Hyper source labeling and WorkBuddy billing cycles.
CodeRabbit's passive usage subprocess disables its automatic updater. Codex
uses the current usage-page link and plan labels.

## Upgrade and compatibility

Install the CLI, daemon and plugins together, then refresh the dashboard. Existing
provider IDs, configuration, history, HTTP `/v1` and optional SDK ingestion
contracts are preserved. No application database migration is required. Balances,
quotas, estimates and billed charges retain their separate meanings; unavailable
measurements remain unknown.

```sh
npm install --global @hashimkarim/usagestat@2.1.0 --include=optional --ignore-scripts
```

See the [installation guide](https://github.com/hashimkarim/usagestat/blob/main/docs/installation.md)
and [publication record](https://github.com/hashimkarim/usagestat/blob/main/docs/releases/v2.1.0-publication.md)
for verified channel availability. Publishing does not change an existing
installation's credentials or start a stopped service.
